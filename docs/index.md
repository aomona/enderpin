# Enderpinについて

Minecraftのクライアントとサーバーを、同じ設定で準備・共有するCLIです。

Minecraft・Java・Fabric・MODのバージョンを固定して、別のPCでも同じ構成を再現します。共有する設定と、手元のワールドや個人設定を分けて管理できます。

## 最初の一歩

1. [インストール](installation.md) — 公開版か、最新のソース版を選ぶ。
2. [初期セットアップ](setup.md) — Minecraftの版・ローダー・MODを選ぶ。
3. [ログインと起動](launch.md) — 権限を確認し、クライアントやサーバーを起動する。

```sh
mkdir my-world
cd my-world
enderpin quick
enderpin launch
```

`quick` は準備、`launch` は起動です。初回のクライアントはオフラインの `Player` で起動します。認証が必要なサーバーへの参加には、アカウント認証の設定とログインが必要です。

## 3つの役割

**`enderpin.toml` は、使いたい構成。** Minecraftの版、ローダー、MOD、ゲームの権限設定を記述します。

**`enderpin.lock` は、実際に決まった配布版。** ダウンロードするファイルの版とハッシュを固定します。通常の同期ではその版を保ち、`update` で明示的に更新します。

**`files/` は共有する入力、`run/` はプレイする場所。** 共通のMOD設定などは `files/` へ。ワールドや個人設定は `run/` に残ります。`run/` はバックアップが必要なデータです。

## このドキュメントの対象

mainブランチの `format = 3` を説明しています。2026年9月25日時点の公開版はv0.1.3（`format = 2`）で、`files/`・`run/` の構成はまだ含まれません。新構成を使う場合は [最新のソース版](installation.md#最新のソース版) をインストールしてください。

主にVanillaとFabricを対象としています。対応OSや未検証の動作は [対応環境と制限](platforms.md)、実行済みのテストは [検証記録](verification.md) にまとめています。
